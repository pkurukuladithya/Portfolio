Engineering Bullet Points

Key Technical Achievements

This project addresses real-world control challenges—bridging the gap between mathematical simulation and physical hardware deployment.

1. System Modeling & Open-Loop Characterization

  • Designed hardware testing protocols to empirically derive the first-order mathematical transfer function of a physical DC motor.
  • Configured hardware-level GPIO interrupts to process high-frequency telemetry from a 700-PPR optical encoder operating at a strict 50ms sampling rate.

2. Full-Stack SCADA Dashboard Implementation

  • Developed a real-time web-based SCADA interface using Flask and Chart.js, allowing remote bidirectional tuning of PID parameters (Kp, Ki, Kd) and target setpoints over a network.
  • Engineered a live heads-up display (HUD) that dynamically calculates and displays critical control metrics (Settling Time, Max Overshoot, Steady-State Error) in real-time.

3. Digital Signal Processing & Embedded Optimization

  • Designed and implemented a 10-point centered moving average filter to eliminate sensor quantization noise, preventing "derivative kick" and violent PWM oscillations.
  • Compensated for non-RTOS Linux CPU scheduling jitter (measured at 1.88ms maximum variance) by programming a dynamic delta-time (dt) calculation into the control loop.

4. Advanced PID Control & Robustness

  • Executed a heuristic tuning methodology to optimize the controller (Kp=0.5, Ki=1.6, Kd=0.01), exceeding all project constraints to achieve a 1.82s settling time, 0.8% maximum overshoot, and 0.0% steady-state error.
  • Engineered an Anti-Windup algorithm (integral accumulator clamped at ±200) to prevent system instability during physical stalling and aggressive setpoint step-downs.
  • Validated system robustness through physical load disturbance testing and automated multi-setpoint trajectory tracking (staircase testing).

Analysis & Evaluation

5. Data Engineering & Performance Analysis

Robustness is proven through rigorous mathematical and empirical analysis, comparing ideal theory against imperfect physical hardware.

Automated Python Data-Logging

Authored automated Python data-logging and graphing scripts using pandas and matplotlib to generate publication-ready step-response and trajectory charts.

Scipy.Signal Simulations

Conducted advanced performance evaluations by running mathematical simulations via scipy.signal and overlaying the theoretical data against empirical hardware responses to analyze system non-idealities (saturation, mechanical stiction).
